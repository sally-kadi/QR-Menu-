
# Brew Co. - Digital Coffee Menu

Brew Co. is a digital coffee shop menu with an admin dashboard for managing menu items and categories.

## Features

- Dynamic customer menu
- Admin dashboard with statistics
- Add, edit, and delete menu items
- Manage menu categories
- Activate and deactivate menu items
- Display product images, descriptions, and prices
- MySQL database integration

## Technologies Used

- PHP
- HTML
- CSS
- MySQL
- XAMPP

## Installation

1. Install and start Apache and MySQL in XAMPP.
2. Copy the project folder into `htdocs`.
3. Open phpMyAdmin.
4. Create a database named `brew_co_db`.
5. Import the `brew_co_db.sql` file.
6. Open the project in your browser:

   `http://localhost/QR-Menu/QR-Menu/index.php`

## Admin Dashboard

Open:

`http://localhost/QR-Menu/QR-Menu/admin/index.php`
